**Time complexity and Space complexity**     --- For Optimization

O(n^2),O(2n), O(n+2), O(n/2), O(n), O(1), O(log(n)), O(e^n), O(nlog(n))

- Constant time O(1), constant space O(1)
- Linear time O(n)
- Quadratic time O(n^2)
- Logarithmic time O(logn)
- Independent time O(2^n)
- Best time O(n//2)
- Constant + linear time O(n+2)
- Exponential time O(2^n)  --- (Tree recursion)
